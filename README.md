# Tornadic-vortex-Utility-Radar-Toolkit-TURT-
A toolkit designed to perform analysis on TVS (tornadic vortex signatures) powered by PyART &amp; Matplotlib in Python






# Dependencies 
1. PyART: https://github.com/ARM-DOE/pyart
2. Matplotlib: https://github.com/matplotlib/matplotlib
3. Tkinter
4. cmweather: https://github.com/openradar/cmweather



Other projects that should be used in-tandem with TURT:
1. https://github.com/ambient330/Graphic-Utility-Radar-Toolkit-V3
